# Jinit Patel Portfolio

Source for [www.jinitpatel.org](https://www.jinitpatel.org), Jinit Patel's aerospace engineering portfolio.

## Development

```bash
npm install
npm run dev
```

Before opening a pull request, run:

```bash
npm run check
npm audit --omit=dev
```

The site is a React and TypeScript single-page application built with Vite and Tailwind CSS. Vercel creates preview deployments for pull requests and deploys the `main` branch to production.
